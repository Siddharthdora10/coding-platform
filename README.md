# Coding Platform

A full-stack coding platform for practicing programming problems, writing and executing code, and submitting solutions.

## Features

* Browse programming problems
* Online code editor
* Run and submit code
* Submission history
* User authentication
* Role-based admin access
* AI coding assistant
* Online code execution using Judge0

## Tech Stack

**Frontend:** React, JavaScript, Vite, Axios

**Backend:** Node.js, Express.js, MongoDB, Mongoose, Redis

**Other:** Judge0, Google Gemini API


## Setup

```bash
git clone <repository-url>

cd frontend
npm install
npm run dev
```

For the backend:

```bash
cd backend
npm install
npm run dev
```

Create the required environment variables in the backend `.env` file before running the application.
